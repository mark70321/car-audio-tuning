# 調音技術驗證 App（車用調音 App・階段 0）

這是「車用調音 App」正式開發前的**測試用小 App**。
目的只有一個：確認一個普通的 App，能不能改變車機（或手機）上**其他 App 播出來的聲音**。

完整的產品規劃寫在 [`PLAN.md`](PLAN.md)，這個 App 對應規劃書第 9 節「階段 0：技術驗證」。

---

## 為什麼要先做這個測試

正式的調音 App 有兩種做法，要選哪一種，看這個測試的結果：

| 測試結果 | 後續做法 | 白話說明 |
|---|---|---|
| 有作用 | **全自動**調音 | App 自己聽、自己算、自己把聲音調好 |
| 沒作用 | **半自動**調音 | App 聽完算出建議值，使用者照著數字手動輸入車機的音效設定 |

## App 畫面說明

整個 App 只有一頁，由上到下分三塊：

### 1. 裝置資訊
自動顯示這台機器的型號、品牌、Android 版本，以及有沒有支援「UNPROCESSED 錄音」。
（UNPROCESSED 的意思是：麥克風錄到的聲音沒被系統自動加工，量測才會準。）

### 2. 系統級 EQ 測試
- **EQ** 就是等化器，可以把某些音域（例如低音）調大或調小。
- App 裡有兩種調整聲音的方式（技術上叫 API），會各自顯示「建立成功」或「建立失敗」：
  - **DynamicsProcessing**：比較新的方式，需要 Android 9 以上
  - **Equalizer（舊 API）**：比較舊的方式，大部分機器都有
- 兩顆大按鈕：
  - **砍掉低音**：把 250Hz 以下的低音大幅調小
  - **恢復原狀**：關掉效果，聲音回到原本的樣子

### 3. 測試清單
四個測試項目，每項用兩種方式各測一次，聽完勾「有作用／沒作用／未測」：
1. 車機本機音樂 App 播放時
2. 車機上的 CarPlay 播放時
3. 車機藍牙音樂播放時
4. 手機上（藍牙／Android Auto 輸出）

勾完按 **「分享測試結果」**，可以把結果用 LINE 等方式傳出去。

## 怎麼測試（操作步驟）

1. 先用**別的 App**播音樂（例如 YouTube Music、Spotify），選低音明顯的歌比較好聽出差別。
2. 切回本 App，選一種方式（DynamicsProcessing 或 Equalizer）。
3. 按 **「砍掉低音」**。
4. 切回音樂 App 聽：低音變小 → 有作用；完全沒變 → 沒作用。
5. 回本 App 按 **「恢復原狀」**，在測試清單勾結果。
6. 換另一種方式、另一個播放來源，重複上面步驟。
7. 全部測完按 **「分享測試結果」**。

> 小提醒：手機本身的小喇叭發不出低音，用手機喇叭測會聽不出差別，這是正常的。請改用藍牙喇叭或車上音響測。

## 怎麼安裝到機器上

### 方法 A：隨身碟（車機適用）
1. 把 `調音技術驗證.apk` 複製到隨身碟。
2. 隨身碟插上車機，用車機的檔案管理員點開 APK 安裝。
3. 如果車機問「是否允許安裝未知來源的 App」，選允許。

### 方法 B：電腦用傳輸線安裝（手機適用）
1. 手機開啟「開發人員選項」裡的「USB 偵錯」，用傳輸線接上電腦。
2. 雙擊專案資料夾裡的 **`install.bat`**。
3. 手機跳出「是否允許 USB 偵錯」時按允許。如果畫面顯示 `UNAUTHORIZED`，按完允許後再雙擊一次。

> 安裝時可能會卡一兩分鐘（手機在做安全掃描），請耐心等，**不要重複按**，重複安裝會把正在開的 App 關掉。

## 給開發者：重新編譯

- 開發環境：Kotlin + Jetpack Compose，Gradle 9.1.0、AGP 8.13.1、Kotlin 2.2.20，compileSdk 36、minSdk 24
- 這台電腦只有 Android Studio 內建的 Java，編譯前要先指定：

```bat
set JAVA_HOME=C:\Program Files\Android\Android Studio\jbr
gradlew assembleDebug
```

- 編譯好的 APK 在 `app\build\outputs\apk\debug\app-debug.apk`
- 電腦模擬器跑不起來（沒有硬體加速），只能用實機測試
