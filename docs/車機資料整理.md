## 已確認（實測讀到）

| 項目 | 內容 |
|---|---|
| 類型 | 換裝的安卓大屏車機（非原廠） |
| 製造商／平台 | alps／tb8163p3_bsp（聯發科 MT8163 公版主機，很多牌子共用這套底子） |
| Android 版本 | 畫面顯示 Android 13，**實際 API 28（Android 9）**。寫程式一律以 API level 判斷，不要相信畫面顯示的版本 |
| 上網 | 平常連手機熱點 |
| 安裝 App | 可用隨身碟裝 APK（SanDisk Cruzer Blade，FAT32），用車機檔案管理員點開安裝，會問是否允許未知來源 |
| 播放 | 車機本機可播 YouTube；可當藍牙喇叭接手機播音樂 |
| 系統音效 | 一般 App 能改變其他 App 的聲音：DynamicsProcessing、Equalizer 都有效（本機播放、藍牙音樂皆是） |
| 內建 EQ（Equalizer） | 5 段，±15 dB，中心頻率 60／230／910／3k／14k Hz |
| 錄音 | 不支援 UNPROCESSED（原始收音） |
| 休眠行為 | 連續播放 30 分鐘、熄火再發動後 App 仍在跑 → 熄火多半是休眠不是真關機 |
| 藍牙延遲 | 手機藍牙播到車機約 440 ms（Note 8）～560 ms（紅米） |
| 車內聲音特性（駕駛座頭枕位置） | 125 Hz 附近低音隆起、500 Hz 凹洞、2 kHz 凹陷 |

## 未確認（做車機介面前建議先查）

- 車機品牌、賣家型號、外觀尺寸（幾吋）
- 螢幕解析度、DPI、是否只有橫向
- RAM／儲存空間、實際效能（MT8163 屬入門等級晶片，介面要做輕量；實際跑起來多順未測）
- 有沒有 Play 商店、有沒有 Google 服務
- 能不能把桌面（Launcher）換成自己的 App、開機是否能自動啟動自己的 App
- 方向盤按鍵、倒車影像、收音機、原車 CAN 訊號（車速、門、燈）能不能被一般 App 讀到
- 開發人員選項／USB 偵錯怎麼打開（公版機常藏起來或要工廠密碼）；USB 孔能不能讓電腦連進來（adb），或只能讀隨身碟
- 真正冷開機（完全斷電）後的行為
- CarPlay 實際表現（需 iPhone）
- 車子本身車型、年份

## 下次上車可以一次查清楚的方法

把一個「裝置資訊」小 App 裝上車機，一鍵把解析度、DPI、RAM、儲存空間、已安裝的系統 App、是否有 Play 商店、Launcher 資訊等全部列出來並存檔。若筆電能用 adb 連上車機，則可直接由電腦讀取。
